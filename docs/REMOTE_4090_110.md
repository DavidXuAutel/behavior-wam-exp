## 问题 1（阻塞）：驱动 R595 与 Isaac Sim 5.1 不兼容

`SimulationApp(headless=True)` 在 `app ready` 之后 **100% 段错误**（8/8、冷热缓存均失败）。

gdb 实测：

```
Thread "carb.tasking14" received signal SIGSEGV
si_addr = 0x3380                      # 空指针 + 结构体偏移，非总线错误
#0  librtx.scenedb.plugin.so
#5  libcarb.scenerenderer-rtx.plugin.so
#8  libomni.hydra.rtx.plugin.so
```

这是 NVIDIA 官方已确认的已知问题：**R595 新特性分支引入的 Vulkan 变更，Kit 107.3.3 的 RTX 渲染器无法处理**；Isaac Sim 5.1 与 6.0 均未验证 R595。相同签名的报告包括同样是 Ubuntu 24.04.4 + RTX 4090 + 595.71 的案例。

### 修复：降到 R580 生产分支（需 root）

apt 源可达，`nvidia-driver-580-open 580.173.02` 可直接安装（≥ 官方要求的 580.65.06），DKMS 会为当前内核 6.17 重新编译：

```bash
sudo apt-get update
sudo apt-get install -y nvidia-driver-580-open   # 自动移除 15 个 595 包，装 16 个 580 包
sudo reboot
nvidia-smi --query-gpu=driver_version --format=csv   # 期望 580.173.02
bash ~/behavior_logs/isaac_repeat.sh 3               # 期望 3/3 passed
```

> 这台机器是共用的（`yao` / `jiehua_a26125` / `zhounan_a26309` 都有数据）。R580 是生产分支，通常比 R595 更稳，但换驱动前建议知会他们。

## 问题 2（性能）：显卡插在 PCH 的 x1 插槽

```
GPU 位于 0000:04:00.0，上游 root port 0000:00:1c.4
00:1c.4  max_link_width = 1        # 主板这个槽只有 1 条 lane
GPU      pcie.link.width.max = 16  # 卡本身支持 x16
实测 pinned H2D/D2H = 0.77 GB/s    # 正常 x16 Gen4 约 20–25 GB/s
```

CPU 直连的 PEG 端口（`00:01.0`）根本没有枚举出来，说明 **x16 槽是空的**，卡插在芯片组 x1 槽或走了 x1 转接线。

不影响正确性，但场景加载、纹理上传、图像回读会慢一个数量级。建议现场把卡移到 CPU 直连的 PCIEX16 槽，之后：

```bash
cat /sys/bus/pci/devices/0000:04:00.0/current_link_width   # 期望 16
```
